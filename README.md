# C++ Programming Course

Solutions, exercises, exams, and course projects from two academic years of C++ programming.

## Structure

- **`23-24/`** — Exercises, `Makefile`, `projeto.odt`, `teste2/`, and the SVG-to-PNG course project (`23-24/project/`).
- **`24-25/`** — Exercises, `CMakeLists.txt`, and the scrim/image processing course project (`24-25/proj/`).

## Building

Each folder or project includes its own `Makefile` or `CMakeLists.txt`. Navigate into the relevant directory and build with `make` or CMake:

```bash
# Example using Make
make

# Example using CMake
cmake -B build && cmake --build build
